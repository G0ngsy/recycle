# 결과 화면과 저장 기록 개선 — 2026-10-14

현재 데이터와 모델을 유지하면서 결과 화면·실패 안내·저장 기록·모바일 사용성을 개선했다. 추가 데이터 수집과 TACO·실시간 인식은 이번 범위에 포함하지 않는다.

## 변경 내용

- 확정 품목명·지역·사진 재질 후보를 결과 상단에 표시하고 품목 수정·수정 취소를 제공한다. 품목 수정 후 새 안내를 받아 새 기록으로 저장할 수 있다.
- 배출 방법 → 지역 요일·시간·장소 → 주의사항 → 공식 근거·분석 상세 순으로 배치했다. AI 본문의 중복 단계 번호는 표시에서 정리하되 수량 표시는 유지한다.
- AI 결과를 확정 판정처럼 표현하지 않고 ‘AI 참고 안내’로 표시한다. 재질·오염 상태·지역 규칙을 확인하도록 안내한다.
- 모델 점수·OCR 문자·공식 원문 발췌는 기본적으로 접혀 있다. 공식 자료의 연도·쪽 번호·원문 링크·지역 기준일은 계속 표시한다.
- 지역명의 ‘없음’ 등 빈 값은 숨기고 관리구역명을 표시한다. 자정을 넘어가는 유효한 시간은 ‘다음 날’로 표현한다. 공식 원본 데이터는 변경하지 않는다.
- 연결·응답 시간 초과·HTTP 처리 오류·읽을 수 없는 응답을 구분한다. 사진·안내 오류 화면에 재시도·직접 입력·지역 재선택과 사진 흐름의 재촬영을 제공한다. 응답 제한은 90초다.
- 갤러리에 품목·지역·저장 날짜·AI 안내 상태를 표시한다. 저장 결과는 저장 당시 정보임을 알리고 최신 정보 확인으로 연결한다. 수정된 품목으로 최신 조회하도록 이전 검색어가 우선하던 경로도 정리했다.
- 버튼의 최소 높이와 초점 표시·텍스트 대비를 보완했다. 확인·결과·오류 화면으로 전환되면 제목에 초점을 이동한다. 사진 확인 단계에서 자동으로 키보드가 열려 후보를 가리지 않도록 했다.
- 기존 저장 데이터에 배출 단계·주의사항·사진·마크 등의 일부 필드가 없어도 기본 안내와 직접 입력을 이용할 수 있도록 유지한다.

## 검증

375×812 모바일 너비에서 가로 넘침이 없고, 제목이 고정 헤더 아래에 표시되는 것을 확인했다. 기존 유리병 기록 열기, 원문·점수 펼치기, Enter 키로 상세보기, 품목 수정 취소, 소주병으로 품목 수정·실제 EXAONE 안내 재생성·새 기록 저장·최신 조회를 확인했다.

점검용 백엔드를 일시 종료해 연결 실패 화면과 직접 입력 버튼을 확인하고, 백엔드를 복구한 뒤 동일 품목의 재시도가 성공하는 것을 확인했다. 실제 평가 사진 `glass123.jpg`를 새로 업로드해 후보 확인·필수 품목 입력·새 결과 화면까지 연결을 확인했다. 안내 생성에 실패해도 지역 정보·공식 자료가 유지되는 경우는 컴포넌트 회귀 검사로 확인했다.

프런트엔드 28개 테스트·타입 검사·린트·빌드 및 변경사항 공백 검사를 통과했다. 백엔드 로직·데이터·학습 모델은 이번에 변경하지 않았다. 실제 휴대폰 카메라 기기 테스트와 실제 촬영 정확도는 별도 검증이 필요하다.
