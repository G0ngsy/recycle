# 배출 지역 저장

- 첫 홈 진입에 저장된 지역이 없으면 시·도, 시·군·구, 실제 배출장소를 선택한다.
- 저장 후 홈의 ‘내 배출 지역’에서 지역과 장소를 확인하고 ‘지역 변경’으로 수정한다.
- 변경 취소는 기존 지역을 유지하며, 저장 오류는 화면에 표시하고 이동하지 않는다.
- 같은 브라우저와 주소에서 새로고침하거나 다시 접속해도 지역이 유지된다. 계정 동기화는 제공하지 않는다.
- 사진 품목 확인과 품목명 검색은 저장된 관리번호를 사용해 지역 선택을 건너뛴다. 저장된 지역이 없으면 기존 지역 선택으로 진행한다.
- 저장 기록의 당시 지역은 변경하지 않는다.

## 검증

- 저장·복원, 변경, 손상 값, 저장소 접근 실패, 기존 기록 보존, 분석 정보 전달을 포함한 프런트엔드 테스트 36개 통과.
- 타입 검사, 린트, 빌드 통과.
- 브라우저에서 최초 설정, 저장 후 홈 표시, 새로고침 복원, 변경 취소, 새 지역 저장, 검색 후 결과 화면 직행 확인.
- 브라우저 검증에는 경기도 가평군의 예시 관리구역을 사용했다. 실제 사용 지역은 홈에서 선택해야 한다.
